# 🎬 Movie Recommendation System

A Machine Learning based Content-Based Movie Recommendation System developed using Python and NLP techniques. It recommends similar movies based on movie features using cosine similarity.

## 📌 Project Overview

This project uses the TMDB 5000 Movies Dataset to recommend movies similar to the movie selected by the user. The recommendation is based on content similarity rather than user ratings.

## ✨ Features

- Content-Based Movie Recommendation
- Data Cleaning and Preprocessing
- Feature Engineering
- Text Vectorization using CountVectorizer
- Cosine Similarity for Recommendations
- Implemented in Jupyter Notebook
